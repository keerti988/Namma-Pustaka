# NammaPustaka 📚

NammaPustaka is an Android application developed for book lovers and students to explore, manage, and access books easily. The app provides a simple and user-friendly interface for reading and organizing educational resources.

## 🚀 Features
- User Login & Registration
- Book Categories
- Search Books
- Book Details View
- Easy Navigation
- Clean UI Design

## 🛠️ Technologies Used
- Kotlin
- Android Studio
- Firebase
- XML
- Gradle
